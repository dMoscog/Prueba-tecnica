# Prueba Técnica - Catálogo de Rick and Morty (Django)

Aplicación web desarrollada en **Python** y **Django** que consume la API oficial de **Rick and Morty**, gestiona una base de datos relacional en **MySQL**, cuenta con paginación, filtros avanzados de búsqueda, autenticación de usuarios y control de acceso basado en roles (**Administrador** y **Editor**).

---

## 🛠️ Tecnologías Utilizadas
* **Python 3.x**
* **Django 4.x**
* **MySQL** (`rick_morty_db`)
* **HTML5 / CSS3 / JavaScript**
* **Requests** (para el consumo de la API externa)
